# 01_basic
html의 기본 구성과 js와의 연결을 다룹니다.
html의 Button을 js에서 불러와 기능을 실행합니다.

# 02_avoid
html의 canvas 구성을 이용해 간단한 피하기 게임을 제작했습니다.
canvas의 작동, html-JS 간의 변수 공유, CSS의 기초 스타일에 대한 내용이 포함됩니다.

# 03_LightsOut
미니게임 LightsOut을 구현한 페이지입니다.
2차원 행렬과 클릭 이벤트에 대한 내용이 포함됩니다.

# 04_sudoku
sudoku 게임을 구현한 페이지입니다.
문제 생성과 같은 복잡한 알고리즘을 적용해 보고, 다양한 연산을 함수화하는 등의 내용이 포함됩니다.
앞선 내용을 적용하는 프로젝트입니다.

# sudoku-react
Vite와 React를 이용해 sudoku 게임을 구현한 페이지입니다.
React 프로그래밍 구조와 component 등의 구조를 학습하는 목적입니다.
메모, 되돌리기, 보드 크기 변환, 시드 입력 등 다양한 기능들을 추가하고 있습니다.
